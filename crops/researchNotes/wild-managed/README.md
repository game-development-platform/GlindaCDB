# Wild-managed resource notes (temporary)

This folder holds temporary research files for resources that turn out to
be wild-managed rather than farmed. A wild-managed resource can't
practically be cultivated; its supply is set by harvest rules (tenure,
seasons, quotas) and by how fast the wild stand regenerates.

They support GitHub issue #2,
https://github.com/game-development-platform/GlindaCDB/issues/2, which is to
research wild-managed resources and create a template for them. Once that
template exists, the content here moves into proper docs, and this folder
is removed.

When a research pass finds that a resource belongs in this category:

1. Save its wild-management research here as `<crop-id-in-kebab-case>.md`.
2. Add a comment to issue #2 linking the file.
