# What is the Glinda Creator Data Bank

Glinda is a collection of human and machine-readable files for use by creators of all types but especially for creators of Role-Playing Games and simulations.

# The role of AI in this project

There are lots of things that AI is absolutely *not* suited for - art, music, and literature, for example but there are also things for which it is absolutely great. Doing grunt work research, tracking down sources, and compiling data into a pre-defined template are things for which an AI is very well suited.

So the data in this project is almost entirely compiled by AI, but it's all sourced to real data out on the web, with real references. Please, feel free to verify *everything* and let me know if there are any errors, gaps, etc.

# Why is it called Glinda?

In the Oz novels by L. Frank Baum, it is made clear that Glinda is the most powerful and knowledgeable sorceress in Oz, and perhaps in the entire world. Part of what makes Glinda so knowledgeable is that she owns the "Great Book of Records" into which is written everything that happens anywhere in the world. 

While this project could never approach that level of detail, we will try to provide as thorough, complete, accurate, and sourced a record of those subjects that are covered as we possibly can.

# How did this madness get started?

I'm an old-school TTRPG player, but I've found several modern video games to be fun and addictive, and one of these is Stardew Valley. I've played several games since then that were primarily farming games or had major farming elements, but anyone who has ever played any of these games knows that there is only a passing resemblance between what's in the game and the actual crops.

I thought to myself that it could be interesting to have a computer moderated RPG that was also an SDV inspired farming game. And I had been tinkering with a CRPG rule set and library for implementing games, but if I was going to do a farming game, I wanted a better crop model - something semi-realistic.

And months of research later, here we are.

# Current plans

At this point, there are four separate data repositories planned.

## Crop data

Every crop grown on Earth, and in enough detail to simulate growing them, harvesting them, processing them into useful products, and eating them.

And also their peculiarities. Across hundreds of Earth species and cultivars there is a tremendous variety of things that set some species apart from others. This is fertile ground for designers and GMs who wish to create alien and/or fantasy crops for their worlds.

## Domesticated Animals

If I'm building a farming game, I'm going to need farm animals.

## Equipment

While the farming game is set in a non-tech magical world, other game ideas I've been working on are set in the future. And space ships, stations, and equipment are all critical elements of those settings.

But even the non-tech setting has primitive equipment, so we need to model that as well.

## Wilderness flora and fauna

Obviously not everything - that would be crazy - but enough to model exploration through a wilderness area of a planet.

## Skills

A hierarchical library of human skills, many broken into specializations. I'm sure that someone is going to argue that I have overlooked something, and I probably have, so please let me know.
